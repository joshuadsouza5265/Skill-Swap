# SkillSwap — Firebase Production Starter

A clean, mobile-first, dark-default SkillSwap platform using Firebase Authentication, Firestore, Firebase Hosting and Cloud Functions.

## What is intentionally NOT included
- No fake users
- No fake reviews
- No fake ratings
- No fake community counts
- No demo login
- No seeded database records

Every member card and dashboard record comes from your Firestore project.

## 1. Create Firebase project
1. Open Firebase Console.
2. Create a project.
3. Add a Web App.
4. Enable Authentication → Sign-in method → Email/Password.
5. Create Firestore Database.
6. Copy the Web App config into `public/firebase-config.js`.

## 2. Install Firebase CLI
```bash
npm install -g firebase-tools
firebase login
```

From this folder:
```bash
firebase use --add
```
Choose your project, then deploy:
```bash
firebase deploy
```

This deploys Hosting, Firestore rules and Cloud Functions.

## 3. First user
Open the deployed URL and choose **Join free**. Your first account becomes a real Firestore user. Ask friends to do the same.

## Firestore collections
The app uses:
- `users/{uid}` — public profile, teach/learn skills, availability, points and streak
- `connections/{id}` — two-person connection requests
- `sessions/{id}` — scheduled learning exchanges
- `assignments/{id}` — tasks between sessions
- `pointEvents/{id}` — server-generated reward history
- `redemptions/{id}` — reserved for a future payout/discount integration

## Important production note
The browser is never allowed to write reward points directly. Completing a session/assignment triggers Cloud Functions, which awards points server-side.

The current redemption UI is deliberately not connected to a fake cash provider. Before launching cash redemption, connect a real payout provider and add server-side redemption processing.

## Recommended next integrations before public launch
- Google/Apple sign-in
- Email verification + password reset
- Push/email reminders for sessions
- Video calls (Google Meet/Jitsi/Zoom integration)
- Calendar integration
- Real cash payout provider
- Admin moderation/reporting
- App Check and stricter abuse controls
- Firestore indexes generated by Firebase when prompted

## Local preview
You can serve the static frontend with Firebase Hosting locally:
```bash
firebase emulators:start
```
Then open the URL shown by the CLI.
